## 1. INTRODUCTION AND PROBLEM STATEMENT
> Left Top
```
✅ Text:
65% of physical rehabilitation patients abandon programmes within 3 months.

✅ Barriers:
• No objective form feedback at home
• No adherence tracking
• Boredom / low engagement
• All existing solutions require gym setup, exposed limbs, specialized hardware.

✅ Required visual:
Simple horizontal bar chart showing adherence dropoff over 12 weeks.
Source literature values:
Week 1: 92%
Week 3: 71%
Week 6: 48%
Week 12: 35%
```

---

## 2. OBJECTIVES AND TARGET USERS
> Right Top
```
✅ Primary objectives:
1.  Enable accurate pose estimation works with occluded traditional clothing
2.  Zero hardware: nothing required except standard smartphone
3.  Improve adherence via gamification
4.  100% on device processing, no cloud

✅ Target users:
• Patients prescribed home physical rehabilitation
• Elderly users, low digital literacy
• All genders, all ages
• Saudi population

✅ Required visual:
User persona diagram / simple icon set
```

---

## 3. PROPOSED SOLUTION
> Left Middle
```
✅ MOVE is a markerless smartphone pose estimation application for physical rehabilitation, trained for occlusion tolerance for thobe / abaya.

✅ Core features:
✅ Gamified exercise feedback
✅ Caregiver alert network
✅ Zero calibration required
✅ Arabic first accessible UI
✅ 100% on device

✅ Required visual:
Simple 1:1 mockup screenshot of the mobile app interface. Show the exercise feedback screen with simple clean mobile UI.
```

## 4. METHODOLOGY AND SYSTEM DESIGN
> Right Middle
```
✅ Pipeline:
1.  Smartphone RGB camera input
2.  MediaPipe Pose Landmarker v3
3.  Occlusion robust keypoint filtering
4.  Rule based form validation state machine

6.  Local session logging
```
